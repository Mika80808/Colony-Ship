指派：Codex　｜　驗收：Claude Code　｜　開單：2026-10-05（第二版：女性向，改設定表）

開工前先讀 `AGENTS.md`。一律用繁體中文寫文件與回報。

## 目的

使用者要從一批外型裡挑出適合當角色的人。立繪要能看出**體型差異**（身高、肩寬、肌肉量、胖瘦、骨架），所以全部穿同一套基礎服裝：**黑色無袖貼身背心＋黑色貼身短褲**，赤腳。不裸體、不性感化，就是一張中性的體型參考。

這批只是候選，**不放進 `public/assets/`，也不接進遊戲**。

## 共同規格（10 張都一樣）

- **這是女性向戀愛遊戲，10 位都是可攻略的男性角色，每一位都要好看、有魅力。** 不要啤酒肚、不要矮小、不要醜化或滑稽化；身高全部 175 cm 以上。體型差異是「不同類型的帥」（纖細、精瘦、勻稱、壯碩、高挑、成熟），不是好看和不好看的差異。
- 全部是成年男性。
- 畫風對齊現有角色立繪：日系動畫插畫、乾淨的深色描線、柔和賽璐璐上色。**把 `public/assets/lucian/profile.webp` 和 `public/assets/blaze/profile.webp` 當參考圖傳給模型，明講只參考畫風，不要畫成這兩個人、不要沿用他們的服裝。**
- 服裝：黑色無袖貼身背心、黑色貼身短褲（大約到大腿中段）、赤腳。沒有其他衣物、配件、道具（C09 的眼鏡除外）。
- 姿勢：自然站立、正面微側（約 15°）、雙手自然垂放並稍微離開身體，讓腰線和手臂輪廓看得出來。不要擺性感、健美或戰鬥姿勢。
- 構圖：全身從頭頂到腳底都在畫面內，直式 9:16，頭頂上方與腳底下方各留約 4% 空白。純淺灰底（約 `#D9D9D9`），沒有地面陰影以外的背景、沒有文字。
- 臉要有辨識度，表情平靜。

## 生圖與處理

- 用內建 imagegen，**一人一張分開生**（不要 10 人擠在同一張，體型會被畫得差不多）。
- 原圖存 `tools/art/candidates/raw/C01.png` … `C10.png`。
- 寫可重跑的腳本 `tools/art/candidates_build.py`：
  1. 每張原圖縮放／補邊成 540×960（比照現有 `profile.webp`），輸出 `tools/art/candidates/C01.webp` … `C10.webp`（無損）。
  2. 產生比較圖 `tools/art/candidates/lineup.png`：10 人並排、**依設定身高等比例縮放**（偵測灰底上人物的上下邊界，頭頂到腳底的高度換算成 cm），底下對齊同一條地平線，背後畫 170／180／190／200 cm 的淡色水平參考線，每人腳下標代號、身高、體型一詞。
- 提示詞全部記在 `tools/art/candidates/prompts.md`，每位一段，附上該位的設定表那一列。
- Python 用系統的 `python`（有 Pillow、numpy）；`tools/.venv` 壞了，不要用。
