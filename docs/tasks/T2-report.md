最該先做的 3 件事：

1. **COMMANDS 驗證與拒收**：數值、任務與記憶寫入都依賴它；先建立可靠邊界，避免錯誤輸出污染進度。
2. **六通道資料結構與注入組裝**：目前 GM 看不到多數故事書與日記；這是記憶回寫、場景快取及摘要流程的共同基礎。
3. **好感度與關係數值**：規則明確、範圍小、不卡美術，可先補每日額度與下限，供日程解鎖及日誌閱讀使用。
