# 中央廣場（規劃中）

星艦正中心的共同生活區，模擬地球的街道生活：吃飯、喝一杯、買東西、開會、辦活動。程式裡的區域 id 是 `park`（目前名稱「中央公園」）。

> 狀態：v3 分區（2026-11-12 使用者定），下一步做底圖。
> 規劃圖：`tools/art/plaza/plaza_plan_v3.png`、`plaza_plan_v3.json`，腳本 `tools/art/plaza_plan.py`（改常數或矩形重跑；會檢查連通、十字主走道淨空、座位數）。
> 全艦配置（使用者給的）：`tools/art/plaza/station_layout_ref.png`。
> **v2（圓形廣場＋圓外星空）已廢棄**：拿去生圖會把星艦畫成盤子。v2 規劃圖與更早的 `plaza_plan.json`（32 × 28）已刪除（2026-11-12）。

## 設定（使用者定）

- 全艦：外環上研究室、右農業區（溫室）、下醫療室、左工程區，四個斜角是居住區；內圈環形通道用輻條接到中央廣場。
- 廣場是四面有牆的矩形室內空間，**不露星空**；全艦唯一的大型觀景舷窗在酒吧裡。
- 風格是室內街道：街道底色跟走廊一致、天花板外露管線；各店風格不同（模擬地球生活），只表現在自己的門面內。
- 中央塔：正中，透明電梯井（為了視線開闊，不做移動的電梯廂），底部霧面玻璃（角色從電梯出來不突兀），外圍一圈電子告示板。電梯往上艦橋、往下接駁口，兼貨梯。
- 廣場不要擁擠，NPC 要能走動。
- 用 RPG 的構圖規劃，店面與物件一律正面朝鏡頭。

## RPG 構圖的限制（為什麼這樣排）

- 鏡頭是斜俯視，只有北牆看得到完整立面；東西牆是窄條、南牆只剩牆頂。所以**所有店面都嵌在北牆**，不佔地板。
- 物件不准露側面（`starport-asset-gen` 第二節範本的 CAMERA 段），所以書架、健身器材、洗手台都面朝下，做成獨立小島或靠北牆，不貼東西牆。
- 塔身往上只畫 4 格（到天花板），切成前景層，玩家在後面時半透明；被擋住的只有 24 格，而且塔是透明的。

### 座位區的三種狀態（共用同一套家具）

- 日常：室外用餐、休息。
- 會議：塔的南面投出電子儀表板；座位全部朝塔，南向主走道是中央走道。全艦 20 位 NPC＋玩家坐得下。
- 活動聚會（例：新年派對）：輸送帶停駛，加掛燈串與裝飾，中央走道擺長桌放食物。

### 貨物運送

- 大型貨物：從塔底進來，走蓋板下的輸送帶往四方區域送；只在補給任務進行時運轉。
- 小型包裹（例：NPC 的信件包裹）：自走運送車在走道上行駛，有動力、不需要淺槽，送到各人臥室（廣場沒有取件櫃）。
- 溫室的蔬果用推車送到餐廳進貨口（沿用既有設定）。

## 畫面

依《場景渲染架構》的七層。物件圖不畫光暈，發光在遊戲裡另外加。

| 層 | 內容 |
|---|---|
| 1 背景 | 地板、牆、北牆店面、塔基座、室外座位、街道物件 |
| 2 動態物件 | 店面廣告螢幕輪播、告示板跑馬燈、輸送帶上的貨物、運送車 |
| 3 Shader | 公共照明色調、螢幕與招牌發光、地面反光 |
| 4 粒子 | 無 |
| 6 前景 | 塔身、大型盆栽 |
| 7 光源 | 路燈、各店門口投射光、塔身環形燈 |

公共照明模擬一天的太陽變化，對齊 NPC 四個檢查點：

| 時段 | 色調 | 亮度 |
|---|---|---|
| 09:00 | 暖白 #FFF4E6 | 100% |
| 18:00 | 橘黃 #FFC48A | 85% |
| 21:00 | 暖黃 #FFD9A0 | 60% |
| 01:00 | 深藍 #3A4A7A | 30%，只剩路燈與店門光 |

主題關鍵字見 `starport-asset-gen` 第四節（廣場與各店已列），不寫死色票；生活區發光色偏琥珀。
